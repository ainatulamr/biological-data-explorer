# Requirements

## Functional requirements (what the system must DO)
1. The system shall allow users to upload CSV file of gene-expression datasets for analysis.
2. The system shall allow users to inspect the uploaded dataset before performing analysing.
3. The system shall identify and handle missing values in the dataset.
4. The system shall calculate descriptive statistics for gene-expression data such as mean, median, standard deviation, minimum and maximum values.
5. The system shall be able to display statistical results in a table.

## Non-functional requirements (how the system must PERFORM)
1. The system shall load the gene-expression dataset from 100 samples within 10 seconds (include a number, for example "within 2 seconds")
2. The system shall complete the statistical calculations within 5 seconds.
3. The system shall produce accurate analysis results.
