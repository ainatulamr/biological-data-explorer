# Problem Statement

## Who is affected?
Research scientists studying gene expressions.

## What exactly is going wrong?
The real gene expression dataset oftentimes includes missing values.

## Why does it matter?
The missing values in the dataset need to be identified and handled before a statistical calculation can be performed accurately.

## Problem statement
Gene expression refers to how active a particular gene is present in a biological sample such as cell or tissue. Scientist measured the gene expression level for various reasons. For example, it is used to determine which genes are active or inactive, how genes behave under different conditions, how gene activity differs between healthy and diseased samples, or which genes might be linked to a particular disease. However, the real gene expression dataset oftentimes includes missing values, which need to be identified and cleaned from the dataset. Only then can the descriptive statistical calculations such as mean, median, standard deviation, or minimum and maximum values can be performed.
